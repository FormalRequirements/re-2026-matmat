=== G.6 Limitations and exclusions

This chapter outlines what is **not** expected from the system to manage stakeholder expectations.

==== Out-of-scope functionalities

[[G6-1]]
^G.6.{counter:g6}^ **No Real-time Chat**::
Real-time instant messaging or chat features between users (like Discord) are excluded.

[[G6-2]]
^G.6.{counter:g6}^ **No Mobile App**::
The development of dedicated native mobile applications (iOS/Android) is excluded; the project is a responsive web app.

[[G6-3]]
^G.6.{counter:g6}^ **No User Accounts**::
User accounts for general visitors are not required; authentication is strictly limited to administrators.

==== Operational constraints

[[G6-4]]
^G.6.{counter:g6}^ **Modern Browsers Only**::
The system does not support legacy browsers (IE); it is optimized for Evergreen browsers (Chrome, Firefox, Safari).

[[G6-5]]
^G.6.{counter:g6}^ **Online Only**::
The system does not provide "Offline Mode"; an active internet connection is required.

[[G6-6]]
^G.6.{counter:g6}^ **Budget Constraints**::
The system infrastructure relies on free usage tiers (Vercel, Firebase); high-traffic scaling is not covered.
