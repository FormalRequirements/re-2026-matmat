=== G.6 Limitations and exclusions

NOTE: Aspects that the system need not address (see {Handbook}).

This chapter outlines the limitations and exclusions explicitly defined for the 404 Association Website project. These constraints are intended to delimit the scope of the system and to make clear what is not expected from its functionality or design. Stating these boundaries helps manage stakeholder expectations and focuses the project on its essential goals.

==== Out-of-scope functionalities

//---- OOO functionality ^G.6.1.{counter:g61}^ Real-time instant messaging or chat features between users (like Discord or WhatsApp) are not part of the system requirements. //----

//---- OOO functionality ^G.6.1.{counter:g61}^ The development of dedicated native mobile applications (iOS/Android) is excluded; the project focuses solely on a responsive web application. //----

//---- OOO functionality ^G.6.1.{counter:g61}^ User accounts for general visitors or students are not required; authentication is strictly limited to association administrators. //----

//---- OOO functionality ^G.6.1.{counter:g61}^ Automated content translation (multi-language support) is not included in the initial release. //----

==== Environmental and operational exclusions

//---- Exclusion ^G.6.2.{counter:g62}^ The system does not support legacy web browsers (e.g., Internet Explorer); it is optimized for modern evergreen browsers (Chrome, Firefox, Safari, Edge). //----

//---- Exclusion ^G.6.2.{counter:g62}^ The system does not provide "Offline Mode" capabilities; an active internet connection is required to fetch dynamic content from the database. //----

//---- Exclusion ^G.6.2.{counter:g62}^ The project does not include the migration of data from previous systems, as no legacy database exists. //----

==== Organizational and technical constraints

//---- Constraint ^G.6.3.{counter:g63}^ The developers are responsible for the technical structure, but the association board is solely responsible for writing and maintaining the editorial content (text, images). //----

//---- Constraint ^G.6.3.{counter:g63}^ The system infrastructure relies on the free usage tiers of the hosting providers (Vercel, Firebase); high-traffic scaling requiring paid plans is not covered in the initial budget. //----

//---- Constraint ^G.6.3.{counter:g63}^ GDPR compliance regarding user data (e.g., contact form entries) is the responsibility of the association's data controller, though the system implements standard security measures. //----
