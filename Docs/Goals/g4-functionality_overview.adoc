=== G.4 Functionality overview

These core functionalities represent the high-level behaviors expected from the web platform.

[[G4-1]]
^G.4.{counter:g4}^ **Public Content Display**::
The system shall display structured information regarding the association's missions, board members, and academic programs to all visitors.

[[G4-2]]
^G.4.{counter:g4}^ **Project Showcase**::
The system shall present a dedicated catalog of student projects, allowing recruiters/partners to view descriptions and visual assets.

[[G4-3]]
^G.4.{counter:g4}^ **Content Management**::
The system shall provide a secured Back-Office interface allowing authenticated administrators to create, update, and delete events dynamically.

[[G4-4]]
^G.4.{counter:g4}^ **Admin Authentication**::
The system shall securely authenticate board members using credentials (via Firebase Auth) before granting access to administrative functionalities.
