[[G5]]
=== G.5 High-level usage scenarios

NOTE: Fundamental usage paths through the system (see {Handbook}).

This chapter describes fundamental usage scenarios from the point of view of stakeholders. These scenarios capture the key interactions between the environment (including users) and the BPS, without entering into implementation details or system-specific terminology.

Each scenario is stated using user-level terms and reflects typical operational situations that justify the system’s existence.

//---- Scenario ==== ^G.5.{counter:g5}^ Student discovers and engages with association activities

A new student (L1) wants to get involved in student life but does not know upcoming dates.

The student accesses the public homepage and navigates to the "Events" section. They view a chronological list of upcoming workshops and parties. They click on a specific event to read the full description and find the location. The student is now informed and can attend without needing to ask for details via private messaging. //----
