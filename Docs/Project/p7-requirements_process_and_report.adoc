=== P.7 Requirements Process and Report

[[P7-1]]
^P.7.{counter:p7}^ **Elicitation Process**::
Requirements were gathered through interviews with the current Association Board and analysis of existing communication channels (Instagram, Discord).

[[P7-2]]
^P.7.{counter:p7}^ **Structuring Standard**::
The requirements are structured according to the **PEGS** methodology (Project, Environment, Goals, System) as defined in the course.

[[P7-3]]
^P.7.{counter:p7}^ **Validation Method**::
Each functional requirement is prioritized using the **MoSCoW** method (Must, Should, Could, Won't) and validated by the Product Owner before implementation.

[[P7-4]]
^P.7.{counter:p7}^ **Traceability**::
Development tasks (GitHub Issues) and Code Commits must reference the unique Requirement ID (e.g., `Ref: S.2.1`) to ensure full traceability.
