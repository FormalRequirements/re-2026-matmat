=== P.4 Tasks and Deliverables

[[P4-1]]
^P.4.{counter:p4}^ **Source Code Repository**::
The complete source code must be hosted on a public GitHub repository (`asso-404-miashs`) with clear commit history.

[[P4-2]]
^P.4.{counter:p4}^ **Deployed Application**::
The application must be accessible publicly via a stable URL (e.g., `https://asso-404-miashs.vercel.app/`).

[[P4-3]]
^P.4.{counter:p4}^ **Requirements Specification**::
A generated HTML/PDF document (this PEGS document) must be provided, detailing all functional and non-functional requirements.

[[P4-4]]
^P.4.{counter:p4}^ **Installation Manual**::
A `README.md` file must be present at the root of the repository, explaining how to install dependencies and run the project locally.
