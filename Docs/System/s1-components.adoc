=== S.1 Components

NOTE: Overall structure expressed by the list of major software parts.

[[S1-1]]
^S.1.{counter:s1}^ **Web Client (Front-end)**::
A Single Page Application (SPA) developed with **React** and **TypeScript**. It is responsible for the user interface, routing, and displaying data to visitors and administrators.

[[S1-2]]
^S.1.{counter:s1}^ **Backend Services (BaaS)**::
Managed by **Google Firebase**. This component includes:
* **Authentication Service:** Verifies user identity.
* **Firestore Database:** A NoSQL database storing structured data (events, members).
* **Cloud Storage:** Stores static assets like event images and profile pictures.
