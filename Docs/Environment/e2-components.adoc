=== E.2 Components

NOTE: List of elements of the environment that may affect or be affected by the system.

[[E2-1]]
^E.2.{counter:e2}^ **Hosting Platform (Vercel)**::
Serves the application to the internet and manages the Continuous Deployment (CI/CD) pipeline directly from the code repository.

[[E2-2]]
^E.2.{counter:e2}^ **Firebase (BaaS)**::
Acts as the external backend service, handling user authentication and hosting the NoSQL database for dynamic content.

[[E2-3]]
^E.2.{counter:e2}^ **User Devices**::
Hardware terminals (Smartphones, Laptops, Tablets) used by students and administrators to access the web platform.

[[E2-4]]
^E.2.{counter:e2}^ **Web Browsers**::
Client-side runtime environments (Chrome, Safari, Firefox) that interpret the code and render the interface to the user.
