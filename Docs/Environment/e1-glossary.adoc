=== E.1 Glossary

NOTE: Clear and precise definitions of the vocabulary specific to the application domain.

[[E1-1]]
^E.1.{counter:e1}^ **MIASHS**::
Mathematics and Computer Science Applied to Human and Social Sciences. The specific university degree program represented by the Association 404.

[[E1-2]]
^E.1.{counter:e1}^ **Front-Office**::
The public-facing part of the website accessible to all visitors (students, partners, recruiters) without requiring authentication.

[[E1-3]]
^E.1.{counter:e1}^ **Back-Office**::
The restricted administration interface accessible only to authenticated Board Members for managing content (events, projects, members).

[[E1-4]]
^E.1.{counter:e1}^ **CRUD**::
Create, Read, Update, Delete. An acronym referring to the four basic operations that the system can perform on data (e.g., managing a news post).

[[E1-5]]
^E.1.{counter:e1}^ **Firebase**::
A backend-as-a-service platform by Google used in this project for authentication and real-time database management.

[[E1-6]]
^E.1.{counter:e1}^ **Board Member**::
An elected student holding an official role within the Association 404 (e.g., President, Treasurer, VP Com), possessing administrative rights on the system.

[[E1-7]]
^E.1.{counter:e1}^ **Evergreen Browser**::
A web browser that automatically updates itself to the latest version (e.g., Chrome, Firefox, Edge), ensuring support for modern web standards.
