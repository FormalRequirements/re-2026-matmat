=== E.3 Constraints

NOTE: Obligations and limits imposed on the project by the environment.

[[E3-1]]
^E.3.{counter:e3}^ **Zero Budget**::
The system must operate entirely within the free usage tiers of the chosen service providers (Vercel, Firebase), as the association has no dedicated budget for IT infrastructure.

[[E3-2]]
^E.3.{counter:e3}^ **GDPR Compliance**::
The system must strictly adhere to GDPR (General Data Protection Regulation) regarding the collection, storage, and right-to-erasure of personal data (students' names, photos, emails).

[[E3-3]]
^E.3.{counter:e3}^ **Mobile Responsiveness**::
The user interface must be fully responsive and functional on mobile devices (smartphones), as this constitutes the primary access method for the student target audience.

[[E3-4]]
^E.3.{counter:e3}^ **Academic Schedule**::
The development lifecycle is constrained by the academic calendar; the core system must be delivered and handed over before the end of the university semester (May/June).
